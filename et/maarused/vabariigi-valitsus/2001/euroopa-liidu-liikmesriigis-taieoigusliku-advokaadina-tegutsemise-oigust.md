# Euroopa Liidu liikmesriigis täieõigusliku advokaadina tegutsemise õigust andvate kutsenimetuste loetelu kehtestamine

Määrus kehtestatakse «Advokatuuriseaduse» § 65 lõike 2 alusel.

Euroopa Liidu liikmesriigis võib täieõigusliku advokaadina tegutseda isik, kes on õigustatud kandma üht järgnevatest kutsenimetustest:
\
Austria Vabariigis: *Rechtsanwalt*
\
Belgia Kuningriigis: *Avocat/Advocaat/Rechtsanwalt*
\
Bulgaaria Vabariigis: *Адвокат*
\
Eesti Vabariigis: *Vandeadvokaat*
\
Hispaania Kuningriigis: *Abogado/Advocat/Avogado/Abokatu*
\
Hollandi Kuningriigis: *Advocaat*
\
Horvaatia Vabariigis: *Odvjetnik/Odvjetnica*
\
Iirimaal: *Barrister, Solicitor*
\
Itaalia Vabariigis: *Avvocato, Procuratore legale*
\
Kreeka Vabariigis:*Δτκηγόρος*
\
Küprose Vabariigis: *Δτκηγόρος*
\
Leedu Vabariigis: *Advokatas*
\
Luksemburgi Suurhertsogiriigis: *Avocat*
\
Läti Vabariigis: *Zvērināts advokāts*
\
Malta Vabariigis: *Avukat/Prokuratur Legali*
\
Poola Vabariigis: *Adwokat/Radca prawny*
\
Portugali Vabariigis: *Advogado*
\
Prantsuse Vabariigis: *Avocat*
\
Rootsi Kuningriigis: *Advokat*
\
Rumeenias: *Avocat*
\
Saksamaa Liitvabariigis: *Rechtsanwalt*
\
Slovaki Vabariigis:*Advokįt/Komerčnż prįvnik*
\
Sloveenia Vabariigis: *Odvetnik/Odvetnica*
\
Soome Vabariigis: *Asianajaja/Advokat*
\
Suurbritannia ja Põhja-Iiri Ühendkuningriigis: *Advocate, Barrister, Solicitor*
\
Taani Kuningriigis: *Advokat*
\
Tšehhi Vabariigis:*Advokįt*
\
Ungari Vabariigis: *Ügyvéd*
